# Digital Marketing Campaign Performance Analysis | Power BI

Find the live interactive version here: https://app.powerbi.com/groups/me/reports/05f8fd36-f485-42b6-af6c-d773d84383d5/08fa937a5c87ec2c1502?experience=power-bi

This Power BI dashboard provides an analysis of digital marketing campaigns on Facebook and Instagram. The project focuses on measuring user engagement, tracking purchases, and analyzing campaign budget to help improve marketing performance.

## Key Dimensions & Features

**Performance KPI Cards:** Shows key campaign metrics, including Total Likes, Comments, Clicks, Shares, Purchases, and Budget.

**Platform Performance:** Compares purchases across Facebook and Instagram to identify which platform generates more purchases.

**Audience Demographics:** Analyzes purchases by Gender and Age Group to understand customer behavior and support better audience targeting.

**Temporal Analysis:** Tracks purchases by time of day to identify periods with higher campaign performance.

**Interactive Filters:** Includes filters for Platform, Date, and Campaign to explore campaign results in more detail.
